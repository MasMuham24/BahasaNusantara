# Bahasa Nusantara 🌏

Website kamus interaktif berbagai bahasa daerah di Indonesia.  
Dibangun menggunakan **React + TypeScript + Vite**.

---

## 🚀 Teknologi Utama
- [React](https://react.dev)
- [Vite](https://vitejs.dev)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com)

---

## 🧭 Fitur
- Kamus berbagai bahasa daerah
- Cerita rakyat dari berbagai provinsi
- Leaderboard & kontribusi pengguna

---

## ⚙️ Cara Menjalankan
```bash
npm install
npm run dev
